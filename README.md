## Adding project media

Use descriptive filenames rather than camera-generated names. Examples:

- `images/climber/01-early-prototype.jpg`
- `images/climber/02-initial-cad.png`
- `images/climber/03-week1-robot.jpg`
- `images/climber/04-redesign-cad.png`
- `images/climber/05-final-climber.jpg`

The climber case study is organized around the engineering process:

**Prototype → initial competition design → competition testing → issues found → redesign → final result**

This site intentionally keeps Danfoss work high-level because manufacturing details may be proprietary.
